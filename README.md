# Правильный кофе — сайт кофейни

Одностраничный сайт кофейни «Правильный кофе» (Королёв, ул. Лесная 14А) с богатым scroll-моушеном: физика кофейных зёрен в hero, sticky-история зерна, горизонтальная галерея сортов, pin-секция обжарки, стопка карточек, бесконечные ленты отзывов и десятки мелких анимаций.

## Запуск локально

Сайт статический, сборка не нужна. Любой HTTP-сервер подойдёт:

```bash
# Python
python -m http.server 8000

# или Node
npx serve .
```

Затем открыть http://127.0.0.1:8000. На Windows можно просто дважды кликнуть `запустить-сайт.bat`.

Для публикации достаточно залить содержимое на GitHub Pages / Netlify / Vercel как есть (корень — папка с `index.html`).

## Стек

| Библиотека | Зачем |
|---|---|
| [GSAP 3.12](https://gsap.com) + ScrollTrigger | все скролл-анимации: reveal, pin, scrub, sticky |
| [Lenis](https://github.com/darkroomengineering/lenis) | плавный скролл с быстрым откликом |
| [matter-js](https://brm.io/matter-js/) | 2D-физика зёрен в hero (падают, сталкиваются, реагируют на мышь) |

Библиотеки подключаются с CDN, шрифты (Unbounded, Manrope, DM Mono) — Google Fonts. Все изображения — WebP в `assets/web`.

## Структура

```
├── index.html        # разметка: 13 секций от hero до футера
├── styles.css        # все стили и адаптив
├── cafe-motion.css   # motion-слой: keyframes, курсор, пыль, карусели
├── script.js         # вся логика анимаций (GSAP/ScrollTrigger/Lenis/matter-js)
├── assets/web/       # оптимизированные WebP (исходники были PNG 2048×2048)
└── запустить-сайт.bat # локальный запуск одним кликом (Windows)
```

## Анимации

- **Hero**: физика зёрен (matter-js), 3D-наклон заголовка за мышью, тёплое пятно света под курсором, параллакс фона
- **Scroll-reveal**: пословное появление заголовков, mask-reveal картинок, stagger-карточки, счётчики статистики
- **Sticky-сторителлинг**: история зерна — 4 этапа со сменой кадров
- **Горизонтальный скролл**: 6 сортов зерна (pin + scrub, drag мышью)
- **Pin-обжарка**: зерно вращается и «обжаривается» (зелёное → коричневое), растёт температура, идёт дым
- **Стопка карточек**: sticky-карты наезжают друг на друга с затемнением
- **Бесконечные ленты**: две карусели отзывов в разные стороны, drag-to-scroll
- **Микро-взаимодействия**: магнитные кнопки, 3D-tilt карточек команды, кастомный курсор с хвостом, превью блюд у строк меню, scramble-цены, skew от скорости скролла, летающая кофейная пыль
- **prefers-reduced-motion**: все анимации отключаются, остаётся статичная композиция

## Производительность

- Страница ~1.1 МБ (исходные PNG 20 МБ сжаты в WebP)
- 60 FPS при скролле; физика и пыль считают кадры только когда hero/вкладка видны
- matter-js с `enableSleeping`: улёгшиеся зёрна не нагружают CPU
